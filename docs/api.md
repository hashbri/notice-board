# 接口文档

> **填法**：先填「接口清单」总表（作业要求的接口文档核心），再给每个接口写详细一节。
> 定稿之后，把这一行注掉或删掉。

- 基础路径（Base URL）：`/api`
- 数据格式：请求与响应均为 `application/json`
- 时间格式：`YYYY-MM-DD HH:mm:ss`
- 统一响应结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

> `code = 0` 表示成功，非 0 表示错误（错误码表见文末）。
