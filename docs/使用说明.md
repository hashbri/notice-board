## 三、安装与启动

### 3.1 拿到代码

```bash
git clone https://github.com/hashbri/notice-board.git
cd notice-board
```

### 3.2 装依赖

```bash
# 后端
cd backend
composer install

# 前端
cd ../frontend
npm install      # 或：无需依赖，直接开
```

### 3.3 配置数据库

1. 新建数据库：
```sql
CREATE DATABASE notice_board DEFAULT CHARACTER SET utf8mb4;
```
2. 导入表结构：
```bash
mysql -u root -p notice_board < backend/sql/schema.sql
```
3. 复制配置模板并填入自己的账号密码：
```bash
cp backend/.env.example backend/.env
# 然后编辑 backend/.env
```
> ⚠️ `.env` 里有数据库密码，**已被 .gitignore 排除，不要提交**。

### 3.4 启动

```bash
# 后端（示例：PHP 内置服务器）
cd backend
php -S localhost:8000 -t public

# 前端
cd frontend
# 直接打开 index.html，或用任意静态服务器
```

### 3.5 验证跑通了

| 检查项 | 期望结果 |
|---|---|
| 打开 `http://localhost:8000/api/articles` | 返回 `{"code":0,...}` |
| 打开前台列表页 | 能看到资讯列表 |
| 打开管理端 → 发布一条 | 列表里出现这条 |
| 列表翻到第 2 页 | 内容变化，页码正确 |

> **这四步全过，才算"跑通"。** 只完成第一步不算。

## 五、常见问题

### Q1：启动后接口返回 500

- 检查 `.env` 是否已创建并填对数据库账号密码
- 打开 PHP 错误日志看具体报错

### Q2：列表页有数据但翻页后空白

- 检查分页参数名是否与 `docs/api.md` 一致（`page` / `size`）
- 检查 `total` 返回的是不是总条数（不是当前页条数）

### Q3：发布成功但列表看不到

- 检查 `status` 字段：草稿状态的资讯是否被列表过滤了
